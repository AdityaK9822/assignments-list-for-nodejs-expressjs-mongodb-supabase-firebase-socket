## 📌 1. Objective & Overview

Build a full-featured backend API for a **Salon & Beauty Spa Appointment Booking Platform** utilizing **Supabase** (PostgreSQL Database as a Service & Authentication engine). In this assignment, students will transition from NoSQL (MongoDB) to a relational database cloud environment (PostgreSQL via Supabase Client), executing SQL-backed queries, foreign key joins, and securing operations using Supabase API keys and JWT tokens.

### Key Learning Outcomes:
- Setting up a PostgreSQL cloud project on Supabase.
- Interacting with Supabase relational tables via the official `@supabase/supabase-js` SDK.
- Relational schema modeling: Salons ➔ Services ➔ Appointments.
- Utilizing Supabase Authentication for user registration, token validation, and session management.
- Performing relational filtering, joins (`select('*, services(*)')`), and transactional booking creation.

## 🗄️ 3. Supabase Relational Database Schema (SQL)

Run the following SQL migration script in your **Supabase SQL Editor**:

```sql
-- 1. Create Salons Table
CREATE TABLE salons (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name TEXT NOT NULL,
    address TEXT NOT NULL,
    city TEXT NOT NULL,
    phone TEXT NOT NULL,
    rating NUMERIC(2, 1) DEFAULT 4.0 CHECK (rating >= 1.0 AND rating <= 5.0),
    opening_time TIME NOT NULL,
    closing_time TIME NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Create Services Table
CREATE TABLE services (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    salon_id BIGINT REFERENCES salons(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    description TEXT,
    price NUMERIC(10, 2) NOT NULL CHECK (price >= 0),
    duration_minutes INT NOT NULL CHECK (duration_minutes > 0),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 3. Create Appointments Table
CREATE TABLE appointments (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID NOT NULL, -- references auth.users(id) in Supabase
    salon_id BIGINT REFERENCES salons(id) ON DELETE CASCADE,
    service_id BIGINT REFERENCES services(id) ON DELETE CASCADE,
    customer_name TEXT NOT NULL,
    customer_phone TEXT NOT NULL,
    appointment_date TIMESTAMP WITH TIME ZONE NOT NULL,
    status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'confirmed', 'completed', 'cancelled')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 📋 4. Complete API Specification

### 🔐 Authentication (Supabase Auth)

| Method | Endpoint | Description | Request Body Payload | Status Codes |
|---|---|---|---|---|
| `POST` | `/api/auth/register` | Register customer with Supabase Auth | `{"email":"client@salon.com","password":"securePass123","name":"Sarah Connor"}` | `201 Created`<br>`400 Bad Request` |
| `POST` | `/api/auth/login` | Login with Supabase, returns JWT access token | `{"email":"client@salon.com","password":"securePass123"}` | `200 OK`<br>`401 Unauthorized` |
| `GET` | `/api/auth/profile` | Get current user's authenticated profile | None (Bearer token in header) | `200 OK`<br>`401 Unauthorized` |

### 💈 Salon Management Endpoints

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `GET` | `/api/salons` | No | List all salons (supports `?city=Mumbai`) | None | `200 OK` |
| `GET` | `/api/salons/:id` | No | Get salon details with all its offered services | None | `200 OK`<br>`404 Not Found` |
| `POST` | `/api/salons` | **Yes** | Register a new salon branch | `{"name":"Glow Studio","address":"Linking Rd","city":"Mumbai","phone":"9876543210","opening_time":"09:00","closing_time":"21:00"}` | `201 Created`<br>`400 Bad Request` |
| `PUT` | `/api/salons/:id` | **Yes** | Update salon details | `{"phone":"9123456780","rating":4.8}` | `200 OK`<br>`404 Not Found` |
| `DELETE` | `/api/salons/:id` | **Yes** | Delete salon | None | `200 OK`<br>`404 Not Found` |

### ✂️ Salon Services Endpoints

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `GET` | `/api/salons/:id/services` | No | Fetch all services for a specific salon | None | `200 OK` |
| `POST` | `/api/salons/:id/services` | **Yes** | Add a service to a salon | `{"name":"Hair Spa","description":"Deep conditioning treatment","price":1200,"duration_minutes":60}` | `201 Created`<br>`400 Bad Request` |
| `DELETE` | `/api/services/:id` | **Yes** | Remove a service | None | `200 OK`<br>`404 Not Found` |

### 📅 Appointment Booking Endpoints

| Method | Endpoint | Auth Required | Description | Request Body Example | Status Codes |
|---|---|:---:|---|---|---|
| `POST` | `/api/appointments` | **Yes** | Book a salon appointment | `{"salon_id":1,"service_id":3,"customer_name":"Sarah","customer_phone":"9876543210","appointment_date":"2026-04-10T14:30:00Z"}` | `201 Created`<br>`400 Bad Request` |
| `GET` | `/api/appointments/my-bookings` | **Yes** | View bookings for the logged-in user | None | `200 OK` |
| `PATCH` | `/api/appointments/:id/status`| **Yes** | Update status (`confirmed`, `cancelled`, etc.) | `{"status":"confirmed"}` | `200 OK`<br>`400 Bad Request` |

## 🏗️ 5. Recommended Architecture & Supabase Client Setup

### Supabase Client Setup (`config/supabaseClient.js`):
```javascript
const { createClient } = require('@supabase/supabase-js');
require('dotenv').config();

const supabaseUrl = process.env.SUPABASE_URL;
const supabaseKey = process.env.SUPABASE_ANON_KEY;

if (!supabaseUrl || !supabaseKey) {
  throw new Error('Missing Supabase environment variables in .env');
}

const supabase = createClient(supabaseUrl, supabaseKey);

module.exports = supabase;
```

## 🧪 6. Testing & Validation Guide

1. Sign up on [supabase.com](https://supabase.com), create a new project, and run the SQL table migrations.
2. Obtain your **Project URL** and **Anon Public Key** from Project Settings > API and paste them in `.env`.
3. Register a user via `POST /api/auth/register` and extract the returned `access_token`.
4. Test booking an appointment via `POST /api/appointments` using the `Authorization: Bearer <token>` header.
5. Retrieve joined data by executing `GET /api/salons/:id` and ensure services are embedded in the response.
